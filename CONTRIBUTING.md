# Contributing

This is a practical toolkit pulled from real client work. Improvements that come from your own tests are welcome.

## How to contribute

1. Fork the repo.
2. Add a new prompt template, case study, or model note that actually worked for you.
3. Keep the tone practitioner level. No hype. Name the tool and the specific result.
4. Open a pull request with before/after notes if you have them.

## What belongs here

- Locked style blocks that survived multiple shots on commercial jobs.
- Negative prompt lists that reduced drift on specific models.
- Small n8n or script snippets that automate reference generation.
- Honest case studies (what failed, what we fixed in post).

## What does not belong

- Generic "best prompts" lists without context.
- Sponsored tool endorsements.
- Theory without at least one real generation test.

Thanks for helping keep this useful for people who ship paid work.
