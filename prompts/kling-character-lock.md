This is the exact style block I copy into every clip for a character. It stays 100% identical across the sequence.

## Action Block (CHANGE PER CLIP)

Action: [specific motion for this shot, e.g. turns head slowly toward camera while speaking product name]

Additional notes: Keep hands relaxed, natural blink rate, micro expressions match dialogue tone.

## How to use with Kling

1. Generate one reference image using the full style block text + "photoreal, commercial lighting, 8k" in Flux or SD3. Use the image as primary reference.
2. In Kling prompt: paste the entire Style Block + the Action Block for this clip. Set image prompt strength to 0.75-0.85.
3. Negative prompt: "face change, different person, clothing shift, hair style change, body proportion change, extra limbs, deformed face, inconsistent lighting"

4. Keep the style block text byte for byte the same in every generation for the sequence.

This separation is what stopped the drift on the last three client campaigns.
